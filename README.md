# go-web-app

Go web application with TailwindCSS.

## Prerequisites

- [Go](https://go.dev/) 1.27+
- [Bun](https://bun.sh/)

## Setup

```bash
go mod tidy
```

## Available Tasks

```bash
go tool task --list
```

| Task    | Description                    |
|---------|--------------------------------|
| `dev`   | Run in development mode        |
| `build` | Build for production           |
| `run`   | Build and run                  |
| `css`   | Build TailwindCSS              |
| `clean` | Remove build artifacts         |
