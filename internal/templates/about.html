About

A production-grade web application template built with Go and Tailwind CSS, featuring dark mode by default.

Tech Stack

Go 1.26

Standard library HTTP server with Go 1.22+ routing patterns. No external frameworks needed.

Tailwind CSS v4

Latest Tailwind with v4 engine, automatic content detection, and CSS-first configuration.

Alpine.js

Lightweight JavaScript framework for interactive UI without the overhead of heavier frameworks.

slog

Structured logging with JSON output, built into the Go standard library.

Architecture

│   │   └── handlers.go
